# Build 312 — Living Visual Identity

Hexfield now preserves and evolves both pixel fragments and sampled geometries.

## Changes

- Evolving vector signatures: each gene has the original 40-point contour and a subtly changed descendant. Smooth contour changes stay related to the original; the root silhouette and counter topology remain represented.
- Real animated creative process: accepted and rejected rendered candidates (bounded 320×200 preview copies), their W / golden-ratio / H trade-offs, inherited contours and executed marks play in the animation theatre.
- Fixed exploratory method selection: even deliberately rotated mixer families now carry their computed W, φ and H assessment. No undefined three-way score interrupts the frame.
- Manual Rule Studio reworks now carry and repaint inherited geometries as well as their original pixel fragments.
- Local recurring signatures: at most four small contour records are saved in browser localStorage. Human KEEP saves the current geometry; repeatedly surviving a lineage can also teach a visual signature. REJECT can remove a saved signature. A later session can recall an old shape and repaint it with a new seed.
- Surviving Ideas interface identifies returned ancestors and evolving materials. Advanced configuration remains collapsed by default.

## Limitations

These features are procedural art experiments, not semantic shape recognition or a scientific definition of beauty. The extractor approximates foreground contour topology from real raster pixels; some images do not yield a suitable gene. Signatures are stored in that device's browser only and can be cleared. Printed artworks use the final selected canvas, not an animation overlay. No additional paid inference or external image storage was added.

## Verification

Automated tests cover deterministic smooth contour mutations, retained root identity and counters, signature retention without storing bitmap data, genealogy, candidate previews, fully scored exploratory branches, multiple generations and existing AI/printing security. Live browser checks are used to confirm the on-page presentation.
